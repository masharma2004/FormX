# FormX

A full-stack form builder: drag-and-drop form creation, sandboxed custom validation scripts, NocoDB spreadsheet sync, and AI-assisted script generation.

## Stack

| Layer | Technology |
|-------|------------|
| Frontend | React 19 + Vite, Zustand, Radix UI + Tailwind CSS, @dnd-kit, React Hook Form + Zod |
| Backend | NestJS, Prisma + PostgreSQL, Passport + JWT, Bull + Redis |
| Integrations | NocoDB (spreadsheet sync), Google Gemini (AI script generation) |

## Structure

```
FormX-Backend/       NestJS backend (REST API, auth, form/script/submission logic)
FormX-Frontend/      React frontend (form builder, dashboard, script editor)
docker-compose.yml   Postgres + Redis for local development
```

## Local setup

1. **Environment**: copy `FormX-Backend/.env.example` to `FormX-Backend/.env` and fill in real values (database URL, JWT secret, Redis, NocoDB, Gemini API key — see comments/blank fields in the example file).
2. **Infra**: `docker compose up -d` (starts Postgres + Redis).
3. **Backend**:
   ```
   cd FormX-Backend
   npm install
   npx prisma generate
   npx prisma migrate dev
   npm run start:dev
   ```
4. **Frontend**:
   ```
   cd FormX-Frontend
   npm install
   npm run dev
   ```

## Testing

```
cd FormX-Backend && npm run test && npm run test:e2e
cd FormX-Frontend && npm run test -- --run
```

## Notes

- Password reset emails are not wired to a real mailer yet — reset links are logged to the server console (`[DEV] Password reset link: ...`) in development.
- `FormX-Frontend/src/lib/zod` is generated by Prisma's zod generator from `FormX-Backend/prisma/schema.prisma` — regenerate via `npx prisma generate` in `FormX-Backend/` after schema changes, don't hand-edit.
